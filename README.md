## 📌 About the Project

**BookNest** is a web-based Library Management System developed as part of a **Value Added Course (VAC)**.

The application is designed to simplify library operations by providing an organized platform to manage books, student details, book issuing, and returning records.

It provides a user-friendly dashboard to monitor library activities and view important statistics.

## 🎓 Course Information

- **Project Type:** Value Added Course (VAC)
- **Project Title:** BookNest – Library Management System
- **Domain:** Web Development
- **Project Purpose:** Practical learning and application development

## ✨ Features

- 📊 **Dashboard:** View library statistics and overview.
- 📚 **Book Management:** Add, search, and manage books.
- 👩‍🎓 **Student Management:** Register and manage student details.
- 📖 **Issue Books:** Issue books to registered students.
- 🔄 **Return Management:** Manage book returns.
- 📋 **Issue Records:** Track book issuing and returning activities.
- 🔍 **Book Search:** Search books by title, author, or category.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Library-Management-System.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Library-Management-System
```

### Step 3: Create a Virtual Environment

```bash
python -m venv .venv
```

### Step 4: Activate the Virtual Environment

For Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### Step 5: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 6: Run the Application

```bash
python app.py
```

### Step 7: Open in Browser

Visit:

```text
http://127.0.0.1:5000/
```
